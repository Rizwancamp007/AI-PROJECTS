# 🤖 AI Projects Repository

This repository contains **Artificial Intelligence and Computer Vision projects** implemented using Python and deep learning frameworks. Each project focuses on solving a real-world problem using practical AI techniques.

## 📁 Projects

* **Image-To-Text OCR** — converts handwritten or printed text images into editable digital text using a Flask app with Tesseract LSTM OCR, OpenCV preprocessing, and CER/WER evaluation.
* **YOLOv3-Image-Detection** — object detection in images using the YOLOv3 model with OpenCV's DNN module, bounding boxes, labels with confidence scores, and non-maximum suppression.

Each project folder has its own README with setup and run steps.

## 📂 Repository Structure

